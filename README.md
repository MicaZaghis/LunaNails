# Turnos Nails by Luna
1. Subí esta carpeta a un repositorio nuevo de GitHub.
2. En Netlify: Add new site > Import an existing project > elegí el repo (sin comando de build).
3. Site configuration > Environment variables: creá ADMIN_PASSWORD con la contraseña de Luna.
4. Editá netlify/functions/config.mjs (alias, servicios, horarios) y hacé commit: Netlify republica solo.
Clientas: tu-sitio.netlify.app  ·  Luna: tu-sitio.netlify.app/admin.html
